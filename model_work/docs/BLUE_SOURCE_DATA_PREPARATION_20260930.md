## 复现

在仓库根目录，用 requirements-pc.txt 对应的 Python 运行：

```powershell
python -B model_work/src/build_reviewed_blue_extension.py --parent model_work/data/hardcase_v5_20260930 --out model_work/data/hardcase_v7_sources_20260930
```

构建器拒绝覆盖已有目录，并默认生成 approved=false。复现时需审核两张新框图，再把审核记录中的 approved 设为 true；本次实际审核、清单身份及来源记录见 docs/hardcase_v7_sources_data_identity.json 和 docs/blue_candidate_label_review_20260930.json。原图与本机训练路径不上传公开仓库。
