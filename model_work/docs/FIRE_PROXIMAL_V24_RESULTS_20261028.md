# 火焰 v23 / v24 接续结果｜2026-10-28

## 实验与证据边界

v22、v23、v24 对比使用已曝光开发数据；新增14图属于训练反馈。九段视频是约1 fps的307同帧采样，没有完整事件真值。没有新增独立测试、ONNX导出、量化或真实上板。四张预留源按协议未参与本次训练或预测；尚未对历史所有预测产物做全局泄漏审计。

v23 做了三组已有检查点插值筛查：全参数6个、部分参数6个、早期特征4个；16个均未达到当时定义的全部实验筛选条件。未由此推断所有候选在项目演示场景都失败。

v24 基于v22同源数据、初始权重和采样设置，加入向v21 last锚点的固定L2-SP梯度。训练12轮、3624 batch、3616次优化更新；冻结前缀/BN/DFL和检查点审计通过。校准目标为0.2，固定系数为1.28066030719。训练日志的比例字段误用开局距离：其0.3001中位数只是开局距离诊断值，不是实际注入比例。按每步保存的当前锚点距离重算，3616次有效更新中裁剪前锚点梯度范数/检测梯度范数的中位数为0.04995、95分位为0.09431，3571次低于0.2；3605次合并梯度范数超过10并触发全局裁剪。日志未保存裁剪后各分量向量，不能由此推断裁剪后的精确分量比例。固定lambda不保证每步比例恒为0.2。历史训练源码与审计保持原样，重算入口为 `model_work/src/audit_fire_proximal_v24_gradients.py`。

## 决策与后续

继续保留 v16 best 演示、v18 last 定位开发；v24 last 保留为进一步对照的开发候选，v24 best保留为参考。本轮不晋升、不替换板端模型。下一步优先复核视频7失框时段和等框数但位置变化的样本，并按厨房/录制事件收集独立正负视频与真值；避免继续反复调参污染四张预留源。
