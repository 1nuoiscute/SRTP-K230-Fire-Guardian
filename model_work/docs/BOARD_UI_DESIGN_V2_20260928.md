## 信息层级

1. 上部保留摄像头画面与检测框；排版图用固定 536×960 尺寸。信息区从底部覆盖 348 像素，不能在真实实现中修改相机输入或检测框坐标；实机需检查画面下部被覆盖的影响。
2. 最醒目的是**火情判断**。在烟雾、气体与融合算法尚未接入时显示“暂未判定”，绝不显示“安全”或“正常”。
3. 第二层是实时可用的 SHT31 温度、相对湿度，以及 BMP280 气压；失联或数据过期时应显示“数据不可用”，不能沿用旧数字。
4. 第三层是烟雾和可燃气体/CO 的固定位置。当前分别显示“未接入”和“预留”；以后新增传感器时不必重排整页。
5. 主板 Wi-Fi 状态位于右上方。只有 `wlan0` 已关联、获得地址并经连通性核验时，才可显示“已连接”。RW007 若以后启用，需要独立标注来源。

视觉风格为浅色中性信息面板、无卡片堆叠的双列数据网格、单一强调色标出“未判定”；不使用渐变、玻璃质感、装饰图标或无意义颜色。文字始终直接标出状态，不单靠颜色传义。屏幕以后可增加故障/网络详情页，但主屏只保留判断所需信息。

## 实机实现前的工程边界

当前可靠的画面来自厂商 ELF 定点修补版，传感器程序运行在另一核心；尚无同源、已验收的主屏 UI 源码，也没有已验证的跨核实时状态接口。因此这一版先冻结为设计稿，不替换板上程序。以后先用新文件名复现原画面和蓝框，再单独接入传感器有效标记与 Wi-Fi 状态，最后按原照片逐项验收显示、框位置、帧率、K1 启停和回退。
