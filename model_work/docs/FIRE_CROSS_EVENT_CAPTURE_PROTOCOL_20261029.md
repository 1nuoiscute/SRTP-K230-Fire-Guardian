## 录制矩阵

每个可录制的厨房分别编号，固定并拍下真实设备安装位置及灶具全貌。使用安全的正常烹饪操作，不要求制造危险或失控火情；如条件不足则留空，不通过猜测补齐。以下是覆盖清单，不代表每行已完成，也不预设样本量足以统计泛化。

| 条件 | 要记录的连续过程 | 观察与边界 |
|---|---|---|
| 固定机位、无遮挡 | 无火基线→点火→稳定燃烧→关火→无火基线 | 记录操作者实际阀门动作时间及其证据；完整连续原件保留，不能从镜头切换推断状态。 |
| 固定机位、锅下蓝焰 | 可见蓝焰稳定燃烧，包含自然遮挡变化 | 标注可见区域和不可判定区间；锅遮住火焰不等于关火。 |
| 关火后的普通操作 | 关火并确认后，锅具、食物、蒸汽或反光等正常活动 | 分开记录实际阀门状态与图像可见性；未知羽流原因不自动标成无烟或烟雾真值。 |
| ROI 外 | 完整画幅中实际可见火焰位于已冻结 ROI 外的合法固定机位事件 | 保留全画幅全程；标注火焰与 ROI 的几何关系，不能将 ROI 外画面裁掉。 |
| 机位变化 | 记录原标定机位，再记录实际位移或灶具移动前后的画面 | 记录变化时间及方向/程度；旧 ROI 在变化后视为未重新确认，重新标定应另记版本，不追溯覆盖。 |
| 不同厨房/事件 | 以独立来源组补录上述条件 | 多帧和同次连续操作不是多个独立厨房或事件。 |

如果 ROI 外场景无法在安全、真实安装条件下采集，明确标记待采，不能仅用计算机裁剪假称真实机位覆盖。记录事件起止、操作人日志或其他能支持状态的证据；帧号/帧率估算时间需与视频时间戳的精度区分。

## 盲标与评估

1. 先按连续时间区间记录物理状态（开、关、未知）及证据，再单独记录图像状态（可定位火焰、未见火焰但视野可判断、遮挡或不可判断）。不要从未见火焰反推阀门关闭；不要从阀门开启反推每帧一定可见。
2. 在事先固定的采样时间点或逐帧，对每个可定位火焰画原画坐标矩形，保存原帧身份、框及遮挡说明；难以确定范围则标不可判定。负例只能在物理状态与画面可判定时确认；先复核并冻结真值，再做预测。单一弧形矩形包含灶具背景时记录该局限。
3. 在原始画幅坐标内判 ROI 关系：框完全处于 ROI 内、完全无交集、部分相交，另设不可判定；使用标注框几何近似，不称真实火焰面积。检查图像尺寸、坐标边界和正面积。ROI 关系按已冻结标定版本计算，机位变化后的旧版本单独报告。
4. 固定预测与真值匹配规则（类别、置信度、IoU 阈值及一对一匹配）后分别记录可见火焰定位漏检、错误位置/重复框，以及已确认无火区间的背景框。不可判定帧不强行计 TP、FP、FN。对完整连续区间记录漏检与背景框的起止、最长持续时间和可观察时长，标明采样间隔与边界精度；抽样不等于逐帧发现所有短时漏检。
5. 逐事件报告，并汇总厨房数、独立事件数、可判定和不可判定时长、ROI 内/外覆盖；相邻帧相关，帧比率不作为独立样本的总体准确率。无足够事件时只报告观察，不外推每小时误报率。常规灶火不是火灾标签；电脑推理与真实 K230 的延迟、稳定性和告警联动分开验收。

## 启动训练的判断

先形成来源清楚、盲标复核和事件角色冻结的样本，再根据开发数据中可重复的问题决定是否训练。候选独立测试不能回流调参而继续称独立；没有足够来源和关火事件时记录缺口，不把当前两个蓝焰短镜头当跨事件测试。
