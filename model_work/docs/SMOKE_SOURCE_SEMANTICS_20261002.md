19 张带全部源类框的完整画面/Smoke 联合区域联系图均已由 Codex 实际目视检查。第 3、6、13 张另打开原始分辨率图核对。

- 17 张可辨认出烹饪器具附近的可见羽流或雾状物。仅凭其外观，无法确定是燃烧烟雾、蒸汽还是油烟；不能批准为火灾烟雾真值。
- 第 3、6 张在源 Smoke 框中未确认清楚羽流，打开完整 640×480/640×482 原图也未能建立可靠对应；保留为位置/语义待核实，不改成负例。
- 画面灶台/橱柜布局高度相似。11 个时间组不能声称为 11 个厨房，19 张也不能代表全量错误率。

本批 **0 张批准作为燃烧烟雾训练真值，0 张改为无烟负例**。这并不否认图片有气溶胶，也不是排除整个来源：当前缺少可验证的事件语义，强行训练 Smoke 会让计划书中的蒸汽/油烟误报测量失去一致口径。下一步可把它们作为“烹饪羽流待判定”审核池，补充有采集说明的烟雾与蒸汽数据，再分别建立标签政策。没有在本次运行中新增 smoke 模型或声称烟雾 F1 达标。
