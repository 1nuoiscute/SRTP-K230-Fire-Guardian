## 新界面方向

[536×960 电脑端排版预览](../ui/board_ui_preview_20260928.html)沿用完整的竖屏画面与蓝色检测框，只在底部覆盖 100 像素、无圆角的简洁状态栏，不改变摄像头输入、检测框计算、模型或显示分辨率。图像来自此前开发视频，仅用于排版。首版主信息只有“仅视觉模式”“1 个火焰框”“烟雾未接入 · 火情未判定”；不显示未经接入的传感器假数值。副板 OLED 继续承担现有温湿度、气压显示。

已用本机浏览器按 620×1150 视口截图并目视检查[最终预览图](../ui/board_ui_preview_20260928_final.png)：检测框完整、文字不溢出、旧开发视频的底部日志字样被状态栏遮住。此检查只针对电脑端排版，不代表板端渲染验收。

## 真正改板端时的验收顺序

1. 先取得与当前厂商 ELF 匹配、能在这块板上复现**完全相同摄像头画面和蓝框**的源码，或先把独立源码修到该程度。以原 ELF 和照片作对照，先只测原样画面、逐帧推理、退出和 K1 启停。
2. 在该已复现源码的 OSD 层加**底部状态条**。摄像头视频层、KModel、检测后处理、蓝框坐标、K1/K2 控制保持原路径。状态条未有真实传感器同步输入时只显示“仅视觉测试/证据不足”。
3. 新 ELF 使用新文件名和单独目录，先在手动测试路径运行；核对单图、实时画面、框位置、帧率、连续运行与退出。失败时停止新程序，原 K1 仍运行存档哈希对应的 ELF。只有新程序经过现场比对后，才考虑切换启动入口。

首版深色底栏样稿已由[完整信息布局 v2](BOARD_UI_DESIGN_V2_20260928.md)替代。当前可交付成果是**可回退存档和不影响板端的界面预览**；板端仍保持用户已确认的显示效果。
