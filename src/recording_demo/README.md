# K230 中期录制程序

当前板上演示版使用 YOLOv8n `last@640`，KPU 固定 200 MHz。相机 VI0 的 960×540 NV12 画面由独立线程取帧并提交 VO1，另一路 1280×720 RGB 供推理。识别框、面板和数据页共用双缓冲 OSD0。写入前检查 VB 引用，退出时停用视频层后才归还仍持有的预览帧。

开机默认摄像头加状态面板。底板 KEY1 显隐面板，KEY2 切换全屏数据页。副板 K1 开关整套视觉，副板 K2 沿用原 Linux 传感器与 OLED 控制器。无外接传感器时读数显示 `--`。

在原 WSL Ubuntu-22.04 构建环境执行 `bash src/recording_demo/build.sh`，默认产物在 `artifacts/recording_demo_20261124`。脚本目前引用原工作目录和已有诊断缓存。移机需配置其中的 RT-Smart 工具链、MPP 用户库和传感器对象、nncase 2.9.0 RTOS 运行库及对应头文件。`low200.elf` 会在会话结束后恢复原档位，视觉程序在未进入 200 MHz 时拒绝启动。GC2093 是固定焦点，相机适配跳过当前固件不支持的焦点供电 ioctl。

安装复用已有 Linux 准备脚本和大核自启入口。`prepare.sh` 校验基础包并优先选择 `/usr/share/srtp_recording_nv12_20261125`，校验失败时依次尝试之前的两个硬件预览包和基础包，最后发布 `READY`。应用截图只包含 OSD 叠加层。版本身份、按键实测与实屏稳定性记录见[演示版与板端故障复盘](../../docs/K230_RECORDING_DEMO_20261125.md)。
