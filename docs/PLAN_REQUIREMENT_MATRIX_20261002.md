另行审核D-Fire可见烟状羽流口径后，完成36图两类开发版本及 [首轮训练/四模型比较](../model_work/docs/SMOKE_FIRE_PILOT_V1_20261002.md)。这与前述烹饪Smoke源的事件语义分别记录；新val只有3个smoke框且已曝光，best/last均TP=0，仍无有效电脑smoke候选。独立测试≥20%、真实厨房≥30%、两类F1≥.90均未因此达成。
