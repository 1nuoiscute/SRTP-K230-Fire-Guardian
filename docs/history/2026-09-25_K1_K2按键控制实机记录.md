## 最重要的已完成成果：两颗实体传感器已跑通

- **SHT31**：副板 `0x44` I²C 通信成功，单次测量曾读到原始字节 `68 A8 A6 6E 8F ED`，温度/湿度双 CRC 均正确，换算 `26.54°C / 43.19%RH`；后续连续采样仍显示 `CRC OK`。
- **BMP280**：副板 `0x76` I²C 通信成功，芯片 ID 寄存器 `0xD0=0x58`；读取校准参数与原始数据后，换算出约 `26–27°C` 和 `952–953 hPa`，连续采样稳定。RT-Smart 硬件 I²C3 也独立读到 ID `0x58`。
