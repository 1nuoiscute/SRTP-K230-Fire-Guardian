# 后续烟雾数据入口｜2026-10-02

Kitchen Safety 的语义抽查没有确认燃烧烟雾真值。后续先审核来源与任务口径，再构建训练版本，不用源类名或模型预测自动补真值。

已核对 [D-Fire 官方仓库](https://github.com/gaia-solutions-on-demand/DFireDataset)：发布者说明约 2.1 万张 fire/smoke/none 图片，YOLO 框格式，并提供图像标签包、预分割版本及官方链接的 Kaggle 镜像。它可作为通用火烟候选来源，不能据此认定满足厨房/蒸汽覆盖或独立测试要求。

[官方 LICENSE](https://github.com/gaia-solutions-on-demand/DFireDataset/blob/master/LICENSE) 将其图像集合声明为 CC0，同时说明发布者不持有所收集图像的版权。当前只记为发布者声明，不替每幅图确认权属，也不将其他来源的许可改成 CC0。使用时保留其论文引用、源版本、原作身份和实际下载身份。

访问记录：官方 README/许可已读取；README 两个 OneDrive 下载入口通过网页工具均重定向失败，官方所链接 Kaggle 页面没有返回可解析的内容。本记录**没有下载、解包、审核或训练该数据**；网页工具失败不意味着数据不可用。下一步可以在公开下载接口核查包大小/响应/许可与版本，写入独立 D 盘目录，失败保留原因，不登录陌生账户或把不明镜像当成官方。

进入训练前的必要数据步骤：实际点清图片/类ID/框数量与异常标签；和现有训练链、曝光诊断做字节及近重复审核；人工抽查 Smoke 与 steam/oil aerosol 的语义；按可证实的原作/采集事件分组。未证明场景独立的默认保持开发诊断，不能把通用野外烟图算成真实厨房样本。无火或无烟标签也需要原始标注和画面核实，不能凭 detector 空框生成。

优先准备小而审核清楚的烟雾开发子集，再比较保留 v3 的火焰能力与新增烟雾能力。新版要求的独立厨房测试和长时蒸汽/油烟误报警需要另外的真实采集证据，通用数据下载不会自动补齐。
